# DemoRepo

A simple front-end web project built with HTML, CSS, and JavaScript.

## Getting Started

Follow these steps to get a copy of the project running locally on your machine.

### Prerequisites

You will need:
- [Git](https://git-scm.com/) installed on your machine.
- A modern web browser (Chrome, Firefox, Edge, etc.).
- *(Optional)* [Visual Studio Code](https://code.visualstudio.com/) with the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension.

---

### 1. Clone the Repository

Open your terminal or command prompt and run:

git clone [https://github.com/VishalNyk/DemoRepo.git](https://github.com/VishalNyk/DemoRepo.git)
cd DemoRepo

2. Run the Project
Since this is a client-side project (index.html, style.css, and script.js), no server or package installation is required:

Option A: Direct Open (Simplest)
Double-click index.html inside the project folder, or

Right-click index.html and select Open with -> your preferred browser.
